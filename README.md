Plant App

About the Project

This application was developed as part of the final exam for the Programming Languages course in the second year of the Computer Science program at Singidunum University.

The application helps users manage and track the care of their houseplants, including watering, fertilizing, and repotting activities, and receive reminders when plant care is due.

Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML5 / CSS3
- Bootstrap 5
- JavaScript
- REST API
